# Stickerly - Sticker Maker

A simple browser-based sticker maker that turns images into downloadable stickers.

## How to use
1. Upload a image (without background is preferable)
2. Adjust the border thickness and color.
3. Preview your sticker
4. Download it in the form of PNG.

## Built with
- HTML
- CSS
- JS
- HTML Canvas API

## Running Locally
Clone the repository and open `index.html` in your browser.

No backend or installation is required.
